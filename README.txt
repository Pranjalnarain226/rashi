RASHI - online karne ke steps (free)

Cloudflare Pages:
1. dash.cloudflare.com pe free account banao
2. Workers & Pages > Create > Pages > Upload assets
3. Folder ke andar ka SAB kuch drag & drop karo:
   index.html, style.css, script.js aur poora "media" folder
4. Deploy dabao, link milega (something.pages.dev)
5. Phone pe test karo (audio/video chal rahe hain ya nahi), phir link ka QR banao: https://www.qrcode-monkey.com
